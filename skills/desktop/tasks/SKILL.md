# Task Recipes Guide (`tasks/`)

This directory contains battle-tested operational recipes for common desktop tasks on Linux Mint.

## Recipe Structure

Each recipe follows the standard **Observe → Plan → Act → Verify** pattern:
1. **Prerequisites & Scope**: Declare session scope and verify required applications or tools exist.
2. **Execution Steps**: Concrete `deskctl` command sequences with error handling.
3. **Verification**: How to confirm success using screenshots, exit codes, or AT-SPI checks.
